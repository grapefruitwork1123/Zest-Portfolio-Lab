# 水湳聖教會 (SNHC) 官網維護案 - 專案說明

## 項目概述
地方教會門戶網站維護與功能擴充，包含線上奉獻、週報系統與活動報名。

## 核心技術
- **Legacy Support**: PHP/Laravel (Backend)
- **New Frontend**: Next.js 16 (Incremental Migration)
- **Database**: MySQL
- **CDN**: Cloudflare

## 效能指標
- **Load Speed**: 提升 150% (導入 Edge Caching)
- **Security**: 通過 OWASP 漏洞掃描

## 原子化設計 (Atomic Design)
- **Atoms**: ScriptureText, DonationButton, EventTag
- **Molecules**: WeeklyBulletinItem, SermonVideoCard
- **Organisms**: EventCalendar, DonationPortal
